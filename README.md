# StrengthSMP texture pack

Resource pack do Strength SMP (modelos do *Strength Item*, do *Revive Kit* , da *Mochila de Couro* e da *Bazuca* (Simple Bazooka RP)). Feito por pipewasxd e beanie.

Download direto (para o `server.properties`):

```
resource-pack=https://github.com/LightzDog0071/StrengthSMP-pack/releases/download/v5/StrengthSMP.zip
resource-pack-sha1=9cbba8fa64350aaf96a7dba59554e4534e453dab
```
