# StrengthSMP texture pack

Resource pack do Strength SMP (modelos do *Strength Item* e do *Revive Kit*). Feito por pipewasxd e beanie.

Download direto (para o `server.properties`):

```
resource-pack=https://github.com/LightzDog0071/StrengthSMP-pack/releases/download/v1/StrengthSMP.zip
resource-pack-sha1=a159ac386c1571317b0899974369af21b9d73ccb
```
